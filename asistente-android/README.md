# Asistente Personal Android (PWA + Gemini AI)

Aplicación web progresiva (PWA) inspirada en la interfaz de mensajes de Android (Google Messages / Material You) con Inteligencia Artificial gratuita mediante Google Gemini.

## 🚀 Despliegue en Vercel o Netlify (1 minuto)

1. Sube esta carpeta a tu repositorio en **GitHub**.
2. Entra a [Vercel](https://vercel.com/) o [Netlify](https://netlify.com/) e importa el repositorio.
3. En la sección **Environment Variables**, añade:
   - **Key / Nombre:** `GEMINI_API_KEY`
   - **Value / Valor:** Tu API Key de Google AI Studio.
4. Haz clic en **Deploy**.

## 📱 Instalación en Android

1. Abre el enlace generado (ej. `https://tu-asistente.vercel.app`) en **Google Chrome** en tu teléfono Android.
2. Toca los **tres puntos** (esquina superior derecha) y selecciona **"Instalar aplicación"** o **"Añadir a pantalla de inicio"**.
3. ¡Listo! Se abrirá como una aplicación nativa independiente en pantalla completa con icono propio.
